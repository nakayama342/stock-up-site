# 株式会社ストック・アップ コーポレートサイト

納品用ソースコード。フレームワーク・ビルド不要の素のHTML / CSS / JavaScriptです。

## ファイル構成

```
dist/
├── index.html          トップページ
├── news.html           ニュース一覧ページ
├── privacy.html        プライバシーポリシー
├── news/               ニュース詳細（記事1本＝1ファイル、日付がファイル名）
│   ├── 2026-07-10.html
│   ├── 2026-06-28.html
│   ├── 2026-06-12.html
│   ├── 2026-05-30.html
│   └── 2026-05-15.html
├── css/
│   └── style.css       全ページ共通スタイル
├── js/
│   └── main.js         モバイルメニュー開閉
└── assets/
    ├── hero-blocks-cut.webp  ヒーロー画像（背景透過）
    ├── news-thumb2.webp      ニュースのサムネイル
    └── docs/                 会社説明資料の抜粋（横スクロールで表示）
        └── slide-p14.webp / p15 / p30 / p44
```

## 使い方

- **確認** — `index.html` をブラウザで直接開くだけで表示されます。
- **編集** — VS Code でこのフォルダを開いてください。
- **公開** — `dist/` の中身をそのままサーバーの公開ディレクトリにアップロードします。

## 実装メモ

- フォントは Google Fonts（Noto Sans JP / Noto Serif JP）を CDN から読み込んでいます。
  オフライン運用する場合はフォントファイルをダウンロードして `@font-face` に置き換えてください。
- 色・フォント・コンテンツ幅は `style.css` 冒頭の `:root` にまとめてあります。
  ここを変えるとサイト全体に反映されます。
- ガラス表現は `backdrop-filter` を使用（Chrome / Safari / Edge / Firefox 対応）。
- レスポンシブのブレークポイントは 1200px（社名非表示）/ 960px（ハンバーガーメニュー）/ 768px / 620px / 480px です。
- `prefers-reduced-motion` 設定時はアニメーションを停止します。
- 「体系化ソリューション」の横スクロールは `assets/docs/` の画像を差し替え・追加するだけで枚数を変えられます（`index.html` の `.carousel__slide` を増減）。

## ニュース記事の追加方法

1. `news/` 内の既存ファイルを複製し、`news/YYYY-MM-DD.html` の名前で保存
2. `<title>` / `<meta name="description">` / 日付（`<time>`）/ タグ / 見出し / 本文 / 前後記事リンクを書き換え
3. `news.html` の一覧（`.news-row`）と注目記事（`.featured__card`）に行を追加し、リンク先を新しいファイルにする
4. `index.html` の「ニュース」セクション（`#news` 内の `.news-row`）を最新3件に入れ替える

## 要確認の項目

- プライバシーポリシー（`privacy.html`）は一般的な雛形をもとにした叩き台です。公開前に内容の確認をお願いします。
- ニュース詳細の本文は仮の文章です。実際の内容に差し替えてください。
- アクセスの最寄駅・所要時間は仮の記載です。
